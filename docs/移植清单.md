# 从 acsus-phone-standalone 移植功能 · 清单与批次

来源：`C:\Users\yona\Documents\deepseek-harness\default-workspace\acsus-phone-standalone`（独立小手机 Acsus Phone，130+ 个模块，约 2.5 MB）。目标是把这套手机里真实可用的功能，按 meme-phone 的架构（`meme/apps/*` + `data.js` 单一存档 + 无弹窗、极简分层）重做一遍，不是把它的 jQuery/DOM 模块原样搬进来。

状态：`已有` / `本批` / `待做` / `不做`（上游已明确删除的占位功能）。

## 批次

- **第 1 批（本批，已完成）**：图片消息 + 看大图、表情消息、戳一戳、撤回、转发、收藏消息 + 收藏页。
- **第 2 批**：钱包与会员 —— 余额、收支明细、转账消息、收/退转账、会员中心、开通与赠送会员、个签历史。
- **第 3 批**：约定计划 —— 计划消息（发起/接受/完成/取消）、计划故事、AI 记账与执行、计划回滚。
- **第 4 批**：联系人与群 —— 好友申请（发/收/通过/拒绝）、群聊与成员管理、联系人分组、备注/特别关心/亲密关系、删除好友与被删除提示。
- **第 5 批**：外观与消息进阶 —— 气泡装扮、聊天背景、消息通知设置、多选与批量转发/删除、存储空间、图片识别模式、角色提示词、联系人正则、帮助中心补全。
- **第 6 批**：模型链路进阶 —— 角色主动消息的定时调度与配额、聊天日记的「总结替换原文 / 按天编辑」、调用调试面板、日志补录角色回复。

## 和上游刻意不同的地方

- 不引入上游的 `state-manager` / `page-stack-helper` / jQuery 依赖：继续用 meme-phone 的 `ctx.go`、`ctx.openSheet`、`ctx.state`。
- 不引入上游的会员/钱包计费规则与价格表：第 2 批只做「本地数字 + 收支明细 + 消息联动」，不接真实支付。
- 上游用独立文件 `acsus-phone-standalone.json`，这里继续写 `meme-phone.json`，字段名尽量对齐但不做旧数据迁移（两套结构不同，README 已写明）。
- 所有新增页面无弹窗、可返回、手机宽度不横向溢出，沿用现有视觉层级。
