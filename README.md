# meme-phone（显示名「meme-phone」）

桌面 + App 图标形态的酒馆小手机前端。整套前端重写：数据单独存在自己的文件里，不写角色卡、不写聊天记录。

## 为什么重做

原来的「独立小手机」把十来个功能压进三个标签页加一个隐藏的加号菜单，功能很多但用不了、入口也找不到。这套换掉的是**外壳与信息架构**：

- 桌面：大字时钟 + 昨日日记卡 + 最近一条会话；下面两行 App 图标，再往下一排快捷动作与 Dock。
- 每个功能是一个 App，进去就是完整一页，回桌面就退出，没有中间层。
- 原来加号菜单里的同步角色、API、预设、分组管理，全部沉到「设置」。

## 背景与返回

- 背景三选一：透明（默认，不铺底色，直接透出酒馆自己的界面）/ 晨光粉彩 / 夜色。在「设置 → 外观与主题 → 背景」里换。
- 返回：每个页面左上角都有「‹ 返回」，回上一页；页面栈到底了就往桌面退。没画返回键的界面由外壳统一补一条，不会再出现「进去了回不去」。
- 图标：桌面与 Dock 的磁贴统一成毛玻璃——半透明渐变 + 背景模糊 + 顶部一圈高光边，日间透着壁纸的粉与薄荷，夜间是磨砂深玻璃；装扮页的图标预览同一套。

## 看界面

双击 `preview.html`。不依赖服务器，壁纸已内联成 data URI，挪到哪都能打开，用的是虚构演示数据（沈砚、江迟、林小满、顾南风、周末局）。

直达某一页：`preview.html#app-chat`、`#app-diary`、`#app-settings`、`#thread`、`#app-contacts`、`#app-wallet`、`#app-extras`、`#app-appearance`；末尾加 `&night` 看夜间主题。

改完 `meme/` 下的源码重新打包：

```
python scripts/build_preview.py
```

## 装进酒馆

把整个 `meme-phone` 文件夹放进 `data/<你的用户>/extensions/`，刷新页面。扩展设置里会多出「meme-phone · 桌面式小手机」，扩展菜单里多一项「meme-phone」。点开就是这台手机。

## 数据

- 位置：`/user/files/meme-phone.json`（酒馆里）/ localStorage（预览页）。
- 写入口只有 `store.flush()`：写完回读校验，失败保留 dirty 并报错，不静默丢数据。
- 备份：手机里「设置 → 数据 → 导出备份」，或扩展设置面板的「导出备份」。

## 这一版有什么、没什么

有：桌面、会话列表、会话页（发送、引用、复制、收藏、重新生成、删除、空输入唤醒主动消息）、通讯录与资料页、日记（日历、手写、让模型代写）、设置（资料、外观与主题、聊天开关、主动消息、提示词、备份、清空）、小剧场、钱包、收藏、表情、会员、计划、装扮、帮助。

没有（明确留白，入口不假装能用）：群聊成员管理、图片消息与查看器、转账流程、调用调试面板、主动消息的定时调度。

## 和旧项目的关系

独立项目，不引用旧项目的代码、命名或存储文件。旧项目保持原样，等这套界面对过之后再谈替换。

## 绘图与接口

桌面多了两个图标：**绘图**（NovelAI）和**接口**（预设）。

- 接口页里一套预设 = 名称 + 引擎（酒馆默认 / OpenAI 兼容 / NovelAI / 自定义）+ 地址 + 路径 + 模型 + Key + 温度。**模型属于这一套，不是单独一项**：换模型就是换一套接口。
- 新建不填空白表：右上角 ＋ 拿当前聊天这套整套复制一份（地址、Key、模型、路径都带过来），改个名字和模型就成了新的一套；详情页里「复制成新的一套」同理。原来的那套不动。
- 换 API：点顶部「聊天用 / 绘图用」两张卡片，弹出的列表就是之前存过的所有 API，另加一套常驻的**酒馆 API**（借酒馆自己的模型，不用填地址、删不掉），随时能切回去。
- 绘图页不自己存地址 / Key / 模型，它读的一定是「绘图用」那套预设，改预设就改出图；绘图页顶部的「接口 · 预设带模型」点进去就是那套。
- 绘图页：画风预设（正向 / 反向，独立的提示词模板，不是接口）、中文画面描述、尺寸 / 步数 / 引导 / 采样器 / 噪声 / 种子，出图后可以「再来一张」。
- 绘图预设没地址 / Key 时不出网，只落一条演示记录并提示去哪填；接上之后走 `POST {地址}/ai/generate-image`，请求体是 NovelAI v4 格式（`n_samples:1`、`qualityToggle:true`、`v4_prompt.caption.base_caption`）。
- 已知限制：NovelAI 官方端点回的是 zip，当前只解 JSON / 直出图片的返回，zip 需要额外的解压库。

## 用户

设置 → 账号 → **用户**。

- 「同步」把酒馆的用户名单整份拉进来：名字和设定读的是酒馆设置里的 `power_user.personas` / `persona_descriptions`，头像直接借酒馆那张。
- 点进某一位可以改名字和设定，改完点「写回酒馆」——只改内存里的 `power_user` 再让酒馆自己 `saveSettingsDebounced()`，不走私有接口。
- 「小手机用谁」两选一：**跟随酒馆切换**（酒馆换 persona，手机 4 秒内跟着换）或**固定一位**（酒馆换人也不动）。
- 没接酒馆时名单是演示数据，改了只会留在本地，写回会提示「没接上酒馆」。

## 查角色

通讯录右上角的放大镜，或 设置 → 生成 → **查角色**。

- 「同步」把酒馆的角色卡拉进来，卡片字段原样读：描述、性格、场景、开场白、示例对话、作者备注、标签、作者与版本（`characters[]` 里的 `description` / `personality` / `scenario` / `first_mes` / `mes_example` / `creator_notes` / `tags`）。
- 放大镜按名字、标签、设定里的任何一段话筛。
- 详情页只读，不会改动酒馆里的角色；想聊就点「存进通讯录」，之后在通讯录里正常打开。
- 没接酒馆时是演示卡。

## 查 TA 的手机

通讯录点进任何一个人 → **查 TA 的手机**（群聊没有这一项）。

- 三个 tab：**聊天**（TA 和家人的私聊、和同事的工作群）、**通讯录**（TA 手机里存的人）、**朋友圈**（TA 发过的动态和别人的评论）。
- 默认这份是本地按角色卡拼的：用卡片里的开场白、场景当素材，进页面就有东西看，不联网。
- 右上角的 ✦ 让酒馆模型按人设现编一份（`description` / `personality` / `scenario` 一起喂进去），要调一次模型，等几秒；没接上就退回本地那份。
- 只读：能翻、能看，不能回消息，也不会写进你自己的聊天。

## 召唤

- 扩展菜单里点 `meme-phone` 打开。
- 也可以在快捷回复（QR）里放一条 `/meme`，点一下召唤手机；仓库里的 `quick-reply/summon-phone.json` 直接导入酒馆的快捷回复即可。
