# meme-phone

酒馆（SillyTavern）里的「小手机」：一台有桌面、有 App 图标的假手机，用来跟角色聊微信、翻日记、听歌、看别人的手机。整套前端是重写的，数据存在自己的文件里，**不写角色卡、不写聊天记录**。

- **形态**：桌面时钟 + 8 个桌面 App + 4 个 Dock App，点开一个就是完整一页，左上角返回，没有中间层和隐藏菜单。
- **两种跑法**：装进酒馆当扩展；或者直接双击 `preview.html` 在浏览器里看（单文件、不用服务器、用虚构演示数据）。
- **依赖**：只需要酒馆本体。酒馆记忆用的柏宝书已经整包放在 `baibai-book/`，不用另装。

## 先看一眼

双击 `preview.html`。壁纸已内联，挪到哪都能打开，数据是演示的（沈砚、江迟、林小满、顾南风、周末局），改动只落在 localStorage。

## 装进酒馆

1. 把整个 `meme-phone` 文件夹放进 `data/<你的用户>/extensions/`。
2. 刷新酒馆页面。扩展设置里多出「meme-phone · 桌面式小手机」，扩展菜单里多一项 `meme-phone`。
3. 点菜单项就打开手机；也可以把 `quick-reply/summon-phone.json` 导进快捷回复，用 `/meme` 召唤。

## 界面与导航

- **桌面**：大字时钟、昨日日记卡、最近一条会话；下面两行 App 图标，再往下一排快捷动作和 Dock。
- **返回**：每个页面左上角「‹ 返回」，回上一页，页面栈到底就回桌面。自己没画返回键的页面由外壳统一补一条，不会「进去了回不去」。
- **背景**：透明（默认，直接透出酒馆自己的界面）/ 晨光粉彩 / 夜色 / 自定义壁纸，在「设置 → 外观与主题」里换。
- **图标**：桌面与 Dock 统一毛玻璃——半透明渐变 + 背景模糊 + 顶部高光边，日间透壁纸的粉与薄荷，夜间是磨砂深玻璃。

## 功能一览

| App | 在哪 | 能干什么 |
| --- | --- | --- |
| 聊天 | Dock | 会话列表、单人会话（发送、引用、复制、重新生成、删除），空输入唤醒对方主动发一条 |
| 通讯录 | Dock | 联系人资料页、新增、从酒馆角色同步；右上角放大镜查角色 |
| 日记 | Dock | 一天一格，日历标出写过和待写；手写或用模型代写 |
| 设置 | Dock | 资料、外观与主题、聊天开关、主动消息、提示词、备份、清空 |
| 小剧场 | 桌面 | 表情包与小剧场：拿角色卡当素材写一段短剧情 |
| 音乐 | 桌面 | 导入网易云 / 汽水歌单，播放器，播不出来自动换源 |
| 绘图 | 桌面 | NovelAI / 豆包 Seedream / 自定义接口出图，提示词预设，再来一张 |
| 计划 | 桌面 | 角色手机里的日程表：未来一周 / 一个月 / 一年 |
| 装扮 | 桌面 | 换图标、换壁纸、夜间主题 |
| 记忆 | 桌面 | 酒馆记忆预设：来源、层数、按会话换一套 |
| 预设 | 桌面 | 回复预设：一段告诉模型「该怎么回消息」的指令，手机一套、单个会话也能换 |
| 接口 | 桌面 | 聊天 API 预设、LLM 整体方案、从酒馆导入 |

聊天设置里还有「TA 的日记」「酒馆记忆」「小剧场」几个入口，点进去是该会话自己的那一份，不跟全局混。

## 聊天

- 会话按联系人排，未读有角标；桌面上直接显示最近一条。
- 单人会话能发、引用、复制、重新生成、删除；**空着直接发送就让 TA 主动开口**（会话设置里可以关掉）。
- 消息是本地数据，**不会写进酒馆的聊天记录**；对方说什么由手机自己的提示词 + 酒馆记忆 + 角色卡组装，再调聊天接口。
- 每个会话可以单独挑一套接口、一套记忆，不挑就跟随手机默认。

## 音乐

歌单只有两个来源：汽水音乐分享链接（`music.doubao.com` 的 `/song/`、`/playlist/`），和网易云的歌单链接 / 歌单 ID。每首歌记歌名、歌手、专辑、封面、歌词，能播就播。

- **放不出来自动换源**：点歌时按「歌单自带地址 → 网易云直链 → 网易云搜索 → QQ 音乐搜索 → 酷狗搜索」逐个试，真出声才算成功，然后把能用的链接写回这首歌存下来。换过源的列表右侧标「网易云·换源」，并弹一次「已自动换源：XX」。
- **放一半断了也能接上**：链接过期、被墙、文件消失时跳过坏链重找，找到就接着播。
- **认的是同一首歌**：歌名（精确或互相包含）加歌手命中打分，对不上就不用，宁可报「没找到」也不放错歌。全都失败就明说「这首暂时没找到能播的音源，可以再点一次重试」，标「暂无可播源」，不无限重试。
- 换歌先把上一首停掉再找源，不会出现「界面是新歌、耳朵里还是旧歌」。
- 换源挂在两个公开接口上：`music-api.gdstudio.xyz`（网易云直链，`source=netease` 可用）和 `api.i-meto.com/meting/api`（`server=netease|tencent|kugou`）。汽水分享页只给前几首，完整歌单是从页面正文（`r.jina.ai`）抠出来的。

## 绘图与接口

- **聊天接口**：一套预设就是「地址 + 路径 + Key + 模型 + 温度」。模型属于这一套，换模型就是换一套接口。列表里常驻一套**酒馆 API**（借酒馆自己的模型，不用填地址、删不掉），随时能切回去。
- **LLM 整体方案**：一套方案 = 一条聊天 API + 一套酒馆记忆，切换时两边一起换；「＋ 存一套」保存当前搭配，齿轮里能改名、复制、删除。
- **从酒馆导入**：只读一次 `oai_settings`，把 `reverse_proxy`、`proxy_password`、当前来源的模型抄成一套新预设。走酒馆内部转发、没有反向代理的那种读不到地址，会提示改手填。
- **绘图接口完全独立**（存在 `settings.image`，不进聊天预设）：引擎三选一，NovelAI 官方 / 豆包·火山方舟 / 自定义 OpenAI 风格接口。
- **接豆包**：地址默认 `https://ark.cn-beijing.volces.com/api/v3/images/generations`，Key 填火山方舟控制台的 `ARK_API_KEY`（不是豆包 App 账号），模型 Seedream 4.5 / 4.0 / 3.0。请求发 `model`、`prompt`、`size`、`response_format: b64_json`、`watermark: false`，4.x 多带一个 `sequential_image_generation: disabled`。
- **提示词预设**跟接口分开：名字 + 正向 + 反向，能建副本、改名、删掉；出图后可「再来一张」。没配好时不出网，只落一条演示记录并提示去哪填。

## 和酒馆的对接

- **数据**：`/user/files/meme-phone.json`（酒馆里）/ localStorage（预览页）。写入口只有 `store.flush()`，写完回读校验，失败保留 dirty 并报错，不静默丢数据。备份在「设置 → 数据 → 导出备份」或扩展设置面板。
- **记忆**：默认读这个角色关联的**最新酒馆聊天**；有柏宝书总结就先扫总结，没有才保留最近几层原文。方案可新建、改名、改来源（自动 / 只用总结 / 只看原文）、改层数。`manifest.json` 里挂了 `generate_interceptor: bbs_generateInterceptor`，酒馆生成前能走到柏宝书的拦截与向量召回。
- **角色**：卡片字段原样读（`description` / `personality` / `scenario` / `first_mes` / `mes_example` / `creator_notes` / `tags` 等），详情页只读，不动酒馆里的角色；想聊就「存进通讯录」。
- **用户**：从 `power_user.personas` / `persona_descriptions` 整份同步，改完「写回酒馆」只动内存再让酒馆自己 `saveSettingsDebounced()`。手机可以跟着酒馆切换 persona（4 秒内跟），也可以钉住一位。
- **查 TA 的手机**：通讯录点进任何一个人（群聊没有）→ 聊天 / 通讯录 / 朋友圈三个 tab。默认按角色卡本地拼一份，不联网；右上角 ✦ 让模型按人设现编一份。只读，不会写进你自己的聊天。

## 已知限制

- 主动消息只有「空着发送」唤醒，没有定时调度；关机、配额、锁这些链路都没做。
- 群聊没有成员管理；没有图片消息与查看器；没有转账流程；没有调用调试面板。
- 旧「独立小手机」的导出配置不能直接导入（两套结构完全不同）。
- NovelAI 官方端点回的是 zip，当前只解 JSON / 直出图片的返回，zip 要额外的解压库。
- 音乐换源目前只有网易云的直链稳定可用：gdstudio 的 `source=kuwo/kugou/tencent` 会让搜索接口 400，meting 的 `server=kuwo` 返回坏数据，所以都没接。
- 只在本地无头浏览器里验过播放和界面；真实酒馆账号的 User 写回、最新聊天读取只做过部分回归。

## 开发

```powershell
npm run check                      # 语法、必备文件、preview 是否过期
python scripts/build_preview.py    # 改完 meme/ 下的源码后重新打包 preview.html
```

约定：

- **改完就提交，不留一堆未提交的改动**。一次提交只装一件事，提交信息照「模块：一句话」，例如 `音乐：放不出来的歌自动换源`。
- 只 `git add` 这一次动过的文件；工作树里有别的会话没写完的东西时，不顺手打包进去。
- 改了 `meme/` 下的源码要跟着重跑 `python scripts/build_preview.py`，`preview.html` 和源码放在同一个提交里，不然别人拉下来看到的是旧界面。
- 不 `--amend`、不 `--force`、不 `--no-verify`；提交前 `git status` 看一眼有没有混进不该进的文件（`_qa/`、`ref/`、`node_modules/` 已在 `.gitignore` 里）。
- 需求文档 `docs/需求文档.md` 的「当前状态 / 提交证据」两列要跟着这次提交一起更新，commit 号写完补进去。
